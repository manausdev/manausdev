Documentação da API

A API pública do ManausDev permite acesso programático a desenvolvedores, projetos, empresas, vagas, eventos e comunidades do ecossistema tech de Manaus.

Base URL

https://api.manausdev.com.br/v1

Formato de resposta

Todas as respostas retornam application/json.

Endpoints

Rate Limiting

Limites de requisição

  • Plano gratuito: 100 requisições por minuto por IP.
  • Plano Pro: 1.000 requisições por minuto por API key.
  • Plano Enterprise: limites customizados.

Os limites são controlados pelos cabeçalhos HTTP:

  • X-RateLimit-Limit — limite atual
  • X-RateLimit-Remaining — requisições restantes
  • X-RateLimit-Reset — timestamp de reset

Ao exceder o limite, a API retorna HTTP 429 Too Many Requests.

Autenticação

API Keys

Endpoints públicos podem ser acessados sem autenticação. Para endpoints protegidos, utilize a header Authorization:

Authorization: Bearer MANAUSDEV_API_KEY

Chaves de API podem ser geradas no painel do desenvolvedor.

Versionamento

Versões da API

A API é versionada via URL. A versão atual é v1. Mudanças incompatíveis serão lançadas como v2, mantendo a v1 operacional por pelo menos 6 meses.

Código de exemplo

JavaScript / Fetch

const API_BASE = 'https://api.manausdev.com.br/v1';

async function fetchDevelopers() {
  const response = await fetch(`${API_BASE}/developers`, {
    headers: {
      'Accept': 'application/json',
      'Authorization': 'Bearer MANAUSDEV_API_KEY'
    }
  });

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${response.statusText}`);
  }

  const data = await response.json();
  console.log(data);
}

fetchDevelopers();
