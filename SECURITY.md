# Política de Segurança

## Relatórios de vulnerabilidade

Se você descobrir uma vulnerabilidade de segurança no **ManausDev**, **não abra uma Issue pública**.

Em vez disso, envie um e-mail para:

**contato@manausdev.dev** (substitua pelo contato real quando disponível)

Inclua no relatório:

- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Sugestões de correção (se houver)

## Nossos compromissos

- Confirmar o recebimento do relatório em até 72 horas
- Fornecer atualizações periódicas sobre o andamento
- Reconhecer publicamente os relatores responsáveis (a menos que prefira anonimato)

## Escopo

Esta política cobre:

- O site principal do ManausDev
- A API e serviços relacionados
- Scripts e automações do repositório

## Divulgação responsável

Pedimos que os pesquisadores:

- Não explorem a vulnerabilidade além do necessário para confirmá-la
- Não divulguem informações públicas antes que a correção seja aplicada
- Ajude-nos a corrigir o problema antes de qualquer divulgação
